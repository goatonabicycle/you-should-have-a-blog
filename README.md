# Type Some Words

The source for [typesomewords.com](https://www.typesomewords.com). It is an Astro site.

Posts live in `src/content/blog/` as Markdown or MDX. A post with `draft: true` is not built and is not in the RSS feed.

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Installs dependencies                       |
| `npm run dev`     | Starts local dev server at `localhost:4321` |
| `npm run build`   | Builds the site to `./dist/`                |
| `npm run preview` | Previews the build locally                  |
